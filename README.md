Myanmar Travel Project
Welcome to the Myanmar Travel repository. This project is an interactive travel and tourism web application designed to showcase key destinations, cultural landmarks, and regional guides across various states and divisions in Myanmar.

Features
Regional Destination Pages: Dedicated HTML layouts covering major states and divisions (e.g., Mandalay, Shan, Kachin, Rakhine, and Ayeyarwady).

Custom Responsive Styling: Lightweight and modular CSS architecture (Main.css and Contact.css) for clean navigation and presentation.

Support & Communication: Integrated contact form (Contact.html) and help resource (Help.html) for visitor inquiries.
